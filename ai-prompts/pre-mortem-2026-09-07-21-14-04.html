Security and privacy.

Failure mode

The supervisor records the raw parent command line, child command line, and task action command in autoresearch-task-launch.json. If a caller passes a secret on the command line, that secret can become durable plain text in the task-state file.

Evidence or rationale

scripts/launch.ps1:323-325 defines -ApiKey, -AzureEndpoint, and -AzureDeployment. scripts/launch.ps1:1853-1877 reads Get-CurrentProcessCommandLine and writes the result into task state.

Recommended mitigation
